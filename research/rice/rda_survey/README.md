## 자료
- `survey.csv`: 연도, 조사 기준일, 공표일·공표처, 항목, 금년·전년·평년 값, 평년 대비 %·전년 대비 %(값에서 계산), 숙기 구분, 출처 URL, 원문 문장.
  - 출처에서 직접 읽은 숫자만 적는다. 계산한 %는 `pct_vs_*` 칸에만 두고, 원문 숫자는 `this/prev/norm` 칸에 그대로.
  - 이미지 PDF(KREI 2018~2024 10월호)는 OCR 후 **쪽 그림을 직접 보고** 숫자를 옮겼다.
- 조사 주체: 농촌진흥청 "벼 생육상황 조사"(2021 표 주석: 국가병해충관리시스템 생육조사, 시·군 농업기술센터 조사). 국립식량과학원 작황시험포(17개 시험소, data.go.kr 15064971)와는 다른 조사이며, 작황시험포 값은 2026 기사 하나만 있다(참고로만 기록).
- 같은 조사라도 보고서마다 '전년' 값이 앞 해에 발표한 금년 값과 크게 다르다(예: 2013 발표 32,308 → 2014 보고서의 '전년' 28,876; 2018 발표 33,531 → 2019 보고서 '전년' 34,153). 표본·집계가 해마다 바뀌는 것으로 보고, **같은 보고서 안의 금년/평년 비율만** 쓴다(연도 사이 절대값 비교 금지).

## 사전 등록 (검정 전에 고정)
1. **주 예측변수 x** = ㎡당 벼알수 평균(전 숙기)의 같은 보고서 평년 대비 % = 100·(금년/평년 − 1). 조사 기준일 9/13~9/16 값(2021만 9/1 기준이 공표됨). 공표는 KREI 농업관측 10월호(9/16~10/2)라 엄격한 9/15 시점보다 1~17일 늦다 → **as-of = 조사 기준일, 실제 공표일은 따로 표시**. 실제 운영이면 API(작황 조사 원자료)로 조사 직후 받을 수 있다는 가정.
2. 평년 대비 값이 없는 해(2018·2019는 전년 대비만 공표)는 주 검정에서 뺀다. 이삭수 × 이삭당 벼알수는 ㎡당 벼알수가 없을 때만 대신 쓴다(이번엔 해당 없음).
3. 목표: (a) 전국 수량 편차 a = common.nation() (올림픽 평년 대비), (b) 작물모델 9/15 8도 합 잔차 r = a_hat − a_obs (cropmodel/out_fixed/contrib_nation_0915.csv, %p).
4. 검정:
   - 피어슨 r(x, a), r(x, a_obs − a_hat) — 부호 기대: x 높으면 a 높고, 작물모델 과소 예측(잔차 음수 방향 보정).
   - 엄격 실시간 보정: â' = â + b·x, b = 그해 이전 해들(≥5년)의 (a_obs − a_hat)를 x에 절편 없이 최소제곱. 대상 연도 전국 RMSE(%p, kg = %·평년/100) 보정 전/후.
   - 표본이 작으므로 leave-one-out(같은 식, 그해만 빼고 b 추정)도 보고.
   - 판정(미리): LOO와 실시간 모두에서 RMSE가 줄고, r(x, 잔차)의 부호가 기대와 같고 |r| ≥ 0.5이어야 "쓸 만한 신호". n<10이면 결론은 "증거 부족"으로만 쓴다.
5. 보조(사후 아님, 미리 적음): 전년 대비 % (전 연도 사용 가능) vs 수량 전년 대비 %, 작물모델 전년 대비 잔차와의 r.
