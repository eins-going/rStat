### 1-3. 전국 결합 (â_N8 = 8도 면적가중 â)
- N1: M4 그대로 (기준)
- N2: 기상 모델 등가중 평균 (M4, FUNC, PHENO; PHENO 없는 해는 둘)
- N3: 제약 최소제곱(w≥0, Σw=1) 가중을 Y−1까지의 표본 밖 전국 â로 맞추고 등가중 쪽으로 축소: w = (n·w_cls + 10·w_eq)/(n+10), n = 학습 연수(모든 구성원이 있는 해, 1996~). n<5면 등가중.
- N4: 예측오차분산 가중 w ∝ 1/MSE_k (학습 기간 전국 오차, 반감기 10년 가중), 같은 축소(n0=10)
- N5 (9/30만): N3에 KREI를 구성원으로 추가 (KREI 없는 해는 나머지로 다시 정규화; 학습은 KREI 있는 해, 2010~)
- N6 (9/30만, 눈 가린 시험 아님): M4와 KREI 등가중 평균
- 결합은 시도에 같은 크기로 더함: 결합 전국 â와 M4 전국 â의 차이 δ_Y를 8도 모두에 더함(=시도 패턴은 M4).

### 1-4. 시도 분배 (κ·평년·편향)
- P0: â_p = â_N + (â_p^M4 − â_N^M4) (M4 시도 패턴 그대로, κ=1)
- P1: â_p = â_N + κ_Y·(â_p^M4 − â_N^M4), κ_Y ∈ {0,0.1,…,1}를 1996~Y−1 시도 상대 편차 면적가중 제곱오차 최소로
- P2 (**주**): P1 + 비율 평년: 시도 평년 b_p 대신 b'_p = (직전 10년 평균 y_p/y_8도) × 상수, 상수는 Σ면적·b'_p = Σ면적·b_p가 되게(전국 수준은 올림픽 평년 그대로, 시도 사이 배분만 10년 비율로). 나머지 시도는 올림픽 평년.
  근거: 상대 편차의 자기상관이 0에 가까우면 5년 중 3년 평균보다 10년 평균이 시도 수준을 덜 시끄럽게 잡음.
- P3: P1 + 시도 편향 보정 β_p = n/(n+10) × (직전 최대 10년 잔차 상대편차 평균), 잔차 = (a_p − a_8도) − κ_Y(â_p^M4 − â_N^M4)
- P4: P1 + 지속성 ρ_Y·잔차_{p,Y−1}, ρ_Y ∈ [0,1] (0.1 간격) 1997~Y−1 최소제곱
