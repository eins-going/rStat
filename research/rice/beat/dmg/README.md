# beat/dmg — 9/30 이전 공개된 시도·시군 피해 정보로 시도 상대 편차 설명

## 사전 등록 (자료 수집 전, 2026-11-09 작성; 수량·오차는 아직 안 봄)

목표: M4 9/15(cropmodel/out_fixed/contrib_sido_0915.csv `ahat`)가 못 잡는 시도 상대 편차
r_s,y = a_s,y − a_8,y (a = 확정/올림픽 평년 − 1, a_8 = 8도 면적가중)를
**그해 9/30 이전 날짜로 공개된** 시도(또는 시군) 피해 자료가 설명하는지 본다.

자료 규칙
- 사고·조사 기준일 ≤ 9/30이고 발표가 10/1 이전(또는 사건 뒤 며칠 안에 발표되는 종류)인 것만.
  연보처럼 나중에 나온 책은 "사건 직후 속보와 같은 값"이라는 가정 아래 근사로만 쓰고 그렇게 적는다.
- 연간 합계 보험금은 수확 후 손해평가가 섞여 누설 → 쓰지 않음.
- 공개 페이지만, robots.txt 준수, 요청 간 ≥1초, 키는 .env에서만(출력 금지), 내려받은 파일은 raw/.

검정 설계 (모든 피처 공통, 미리 고정)
- 피처 x_s,y: 피해 면적(ha) / 그해 시도 논 면적(ha) (= 비율, 0~1). 피해 유형이 여러 개면
  (i) 전체 합 D_all (주), (ii) 유형별(침수·도복·백수/병해충) 보조. 자료 없는 시도-해는 0
  (보도에서 "피해 없음"으로 본다; 자료 자체가 없는 해는 결측으로 빼지 않고 그 자료가 덮는 해만 평가).
- 상대화: x̃_s,y = x_s,y − (8도 면적가중 x_8,y) (시도 상대 피처).
- 모형 (주, D1): r_s,y − (â_s,y − â_8,y) = β · x̃_s,y  (절편 없음, M4 잔차의 시도 상대 부분에 대한 회귀),
  β는 Y−1년까지의 모든 시도-해로 OLS(확장 창). 학습 시도-해가 0이 아닌 x̃를 가진 해 수가 3 미만이면 β=0.
  보정 â'_s,y = â_s,y + β·x̃_s,y. 8도 평균은 바뀌지 않으므로(가중 합 0) 전국은 거의 그대로,
  다만 nat_from_prov가 8도 외 시도를 8도 평균으로 채우므로 전국 값은 같다.
- 보조 (D2): β를 [−∞, 0]으로 제한(피해가 많으면 상대 수량 낮음).
- 보조 (D3): 시도 상대화 대신 수준 피처로 â' = â + β·(x − x̄_train) — 전국에도 영향.
- 평가: beat/prov/evalp.py 방식 그대로(8도 면적가중 RMSE, 전국 MAE/RMSE, 2013~2025 및 자료가 덮는 해),
  M4·통계청과 같은 해 비교. 시군 자료가 있으면 common.evaluate(pred_sigun_0915 기준)로 시군 내 γ도 같은 방식.
- 판정 기준(미리): 8도 면적가중 RMSE가 M4보다 ≥0.3 줄고, 해 짝 비교에서 나아진 해가 절반 이상이면 "신호 있음".
  자료가 5~8년뿐이면 "증거"로만 보고, 검증된 모형이라 하지 않는다.
- 시도한 변형은 모두 아래 표에 기록.

## 사전 등록 보충 (자료 수집 후, 수량과의 관계는 보기 전, 2026-11-09)

자료 조사 결과 쓸 수 있는 것은 (1) NCPMS 작물/병해충별 예찰결과(공개 화면, 키 없음, 2014~2026 시군, 회차 6/1·6/16·7/1·7/16·8/1·8/16·9/1·9/16,
병해충 12종 × 발생면적율·발생추정면적·피해율)과 (2) 농식품부 보도자료의 사건별 시도 피해 면적(드문드문, 완전한 시도 표는 몇 사건뿐)이다.
그래서 (1)을 주 검정, (2)는 증거용 보조로 한다.

### 주 검정: NCPMS 병해충 (변형 미리 고정)
- 병해충 집합 K(수량에 직접 닿는 늦은 시기 9종): 이삭도열병·벼멸구·흰등멸구·세균벼알마름병·깨씨무늬병·흰잎마름병·혹명나방·먹노린재·이삭누룩병.
  잎집무늬마름병(해마다 넓게 보고, 감수 약함)·잎도열병·애멸구(초기·매개충)는 뺀다.
- 피처 F_area = Σ_K 발생추정면적(시군 합, ha) / 그해 시도 논 면적(KOSIS, 8월 말 조사로 알려짐).
- 회차: **주 = 9/16 회차**(조사일 9/16, 화면 게시 시점은 확인 못 함 — 9/30까지 게시된다고 가정, as-of 9/30 취급; M4 9/15에 더함),
  보조 = 9/1 회차(엄격 as-of 9/15).
- 변환: **주 = 자기 과거 평균 대비 편차**(그해 이전 NCPMS 해들의 평균, 이전 해가 없으면 0) → 8도 면적가중 평균을 빼 시도 상대화.
  보조 = 수준(편차 아님) 상대화.
- 모형: D1(주) r_res = β·x̃ (절편 없음, OLS, 확장 창, 피처가 정의된 학습 해 ≥ 3년일 때만, 아니면 β=0).
  D2 β ≤ 0 제약. D3 수준 효과(상대화 안 함, 전국에도 영향): a − â = β·x_anom (시도-해 풀링, 절편 없음).
- 보조 피처: F_dmg = Σ 12종 피해율(시군 평균)의 같은 변환 — D1만.
- 시군: 같은 시도 안 (a_g − a_s) = γ·(x_g − x_s), x_g = Σ_K 발생면적율_g/100, 자기 과거 평균 편차, 확장 창 γ(학습 ≥3년);
  M4 시군(pred_sigun_0915) 위에 시군 보정만 얹어 common.evaluate. 9/16 회차.
- 사전 판정: 위 기준(8도 RMSE −0.3 이상, 해 짝 절반 이상 개선)은 **주 변형(D1·F_area·9/16·편차)** 하나로 판정. 나머지는 참고.
- 변형 수(미리): 시도 D1×{9/16,9/1}×{편차,수준} 4 + D2 1(9/16 편차) + D3 1(9/16 편차) + F_dmg 1 + 시군 1 = **8**.
  추가로 하는 것은 '사후'로 따로 적는다.

### 보조 검정: 농식품부 사건 피해 면적 (증거용, 모형 아님)
- x = 사건 보고(≤9/30 발표)의 벼 피해 면적(도복·침수·백수 합; 벼 구분 없으면 농작물) / 시도 논 면적, 같은 해 여러 사건은 합.
  "등"으로 끝나는 상위 N개 시도 보고는 나머지 시도 0으로 둔다(과소 가능, 주의).
- 시도가 4개 이상 나온 해만: 시도 상대 x̃와 M4 시도 상대 잔차의 해별 상관, 풀링 기울기(한 해 빼기) 보고. 운영 모형으로는 안 씀.

## 결론
- 9/30 이전 공개 시도 병해충 예찰(NCPMS, 2014~)은 M4가 못 잡는 시도 상대 편차를 설명하지 못함(사전 등록 탈락, 변형 11개 모두 8도 나빠짐 또는 같음).
  9/16 조사는 늦게 번지는 병해충(2021 전북 이삭도열병: 10월의 1/4, 2024 벼멸구 전남 6,608 vs 9/30 19,603)을 덜 보고, 해마다 병해충 면적과 감수의 관계가 뒤집힘(2020).
- 사건 피해 면적(벼 백수·도복·침수)은 **큰 사건에서는 방향·크기 모두 맞는 신호**(2010·2012 r −.8~−.9, β 안정)지만,
  시도 표가 다 나오는 사건이 15년에 몇 개뿐이고 2013~2025에는 큰 사건이 없어 13~25 8도는 그대로. 검증된 모형 아님.
- 운영: 큰 태풍·호우 뒤 농식품부가 시도 벼 피해 면적을 내면(보통 1~8일 뒤, 잠정치) β ≈ −0.45로 시도 상대 보정을 얹는 '규칙'은 근거가 있음(2012형 해). 평소 해에는 0.
