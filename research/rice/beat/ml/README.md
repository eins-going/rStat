### 해석
- 사전 판정 기준(두 기간 모두 전국·8도 RMSE < 통계청) 충족 변형 0개. 주 결과 E1은 전국 MAE만 5.50으로 통계청(5.65)보다 낮지만 RMSE·8도는 못 미침.
- 나무·커널·GP 모두 M4 릿지보다 나빴다. 내부 CV(G1cv)는 부스팅 횟수로 대개 0~50을 골라 M4로 돌아갔고(2026은 0), E2 메타 선택도 대부분 R0. 30여 해 × 8도(도끼리 상관 높음)로는 비선형 상호작용을 배울 자료가 모자라고, 큰 오차 해(2020 영화수, 태풍)는 이미 M4의 문턱 지표가 잡는다.
- **8도 격차의 원인**: 8도 오차를 그해 공통 부분과 도 특유 부분으로 나누면(2013~25) R0 = 공통 7.6 + 도 특유 10.9, 통계청 = 7.2 + 6.6. R0의 도 특유 오차 10.9는 평년의 도 특유 오차 10.87과 같다 — 기상 모델은 도 사이 차이를 전혀 맞히지 못한다. 전국 단수를 미리 정확히 안다고 해도(오라클) 도 비율을 과거 값(올림픽·지수가중 등)으로 내면 8도 RMSE 10.4~10.7로 통계청 9.78보다 나쁘다. 설계 기간(1985~2012) 1년 빼기 진단에서 그해 평균을 뺀 도 특유 a를 기상 편차로 설명하는 skill은 −0.11~+0.02. 즉 9/30 이전 공개 기상만으로는 8도 시도 RMSE에서 통계청(표본 실측)을 이기기 어렵다.
- 시군 패널 학습(S1)은 1996~2012 8도에서 상대적으로 좋았으나(25.5 vs 평년 29.1, 다만 2006~만 가능) 2013~25 전국·8도 모두 나쁨.
