# solar — 위성 일사(NASA POWER)를 작물 모델 입력으로 (11-10)

## 동기 (check_power.py)
일사계 관측소 19곳에서 출수 전 창(7/10~8/9) 일사 합의 해마다 편차를 실측과 비교 (그 관측소 제외):
- 지금 입력(이웃 3곳 일조 → Ångström): 상관 0.75, 편차 RMSE 58 MJ/m² (2001~25) / 0.76 (1985~2000)
- POWER ALLSKY_SFC_SW_DWN(CERES SYN1deg, 1984~2000 SRB): 0.87, 40 / 0.82 — 19곳 중 18곳에서 나음.

## 사전 등록 (결과 보기 전)
- 입력 변형(일사 외 기상·생육단계·모델 M4·λ·학습 1985~ 모두 그대로):
  - P1: rs ← POWER (시군 논 중심 0.5° 격자). 출처가 바뀌는 시기(1984~2000 / 2001~)마다 달별로 지금 입력 평균에 비율을 맞춤(수준 끊김 제거). 1980~83은 지금 입력 그대로.
  - P2: P1 + '흐린 날'(일조<1h) 판정을 POWER 맑음 비(ALLSKY/CLRSKY) 문턱으로 바꿈(문턱은 시군마다 1985~2012 흐린 날 빈도가 같아지도록).
  - P3: rs = (지금 입력 + P1)/2.
- 주 비교: 9/15, 보조 8/15·10/1. 지표: 8도 시도 RMSE(kg, 2013~25·2010~25), 시군 skill(B0p 아님, run_final 방식), 전국 RMSE.
- 채택(주 변형 P1, 다른 변형은 사후 표시): 9/15에서 8도 RMSE −0.3kg 이상(2013~25와 2010~25 둘 다) 그리고 시군 skill 하락 없음, 전국 RMSE 악화 0.3kg 이내; 10/1에서 나빠지지 않음(+0.3 이내).
- 통과하면 prod 파이프라인 반영 검토(POWER 지연 약 5일 → 주간 갱신과 맞음).

## 결과 (11-10, run_variants.sh → out_{A,P1,P2,P3})
| 9/15 시도 RMSE(kg, 8도 면적가중) | 1996~2004 | 2005~2012 | 2013~2025 |
|---|---|---|---|
| A 지금 입력 | 38.97 | 20.71 | **13.32** |
| P1 POWER | 32.15 | 21.47 | 15.44 |
| P2 POWER+흐린 날 | 31.02 | 20.82 | 14.81 |
| P3 반반 | 35.40 | 22.36 | 13.91 |
- 시군 skill 9/15: A +0.304 · P1 +0.255 · P2 +0.271 · P3 +0.290 (run_final 방식). 10/1도 같은 순서. → **사전 기준 미달, 탈락.**
- 성분 하나씩은 POWER가 단수와 더 맞음(출수 전 일사 편차 상관 2001~25 0.35→0.43, 등숙 0.60→0.62)인데 모델은 나빠짐. 1996~2004만 좋아지고(그때는 학습 연수가 짧아 오차가 큰 시기) 2005년 이후는 나빠짐. 2018(+4.2%p)·2013(−2.3%p) 전국 오차가 커짐.
- 해석: M4 성분 설계(창·문턱·흐린 날)가 지금 입력으로 2013~25에 맞춰 골라진 몫이 있고, 입력이 더 정확해져도 시도 단수 오차의 남은 부분은 일사 측정 오차가 아님. 일사 입력 개선 갈래 종료.
