## 자동으로 받지 못하는 자료와 갱신 방법

### 물류기기 공동이용 실적 (물류동향·물류기기 사업동향) (수동 파일)
- 확인 주기: 12개월 — 매년 1~2월 전년도 실적 파일
- 공개 내려받기 주소가 없는 원자료다. 제공처에서 연도별 CSV(cp949)를 받는다.
- agri_distribution_data/에 'YYYY년 물류기기 공동 이용-작성일.csv' 꼴로 넣는다 (같은 연도의 예전 파일은 지운다).
- 다음 자동 실행 때 정제 → DB → 원자료 대조 검증 → 집계가 돌고, 검증을 통과하면 배포된다.
- 넣을 자리: `agri_distribution_data/*.csv`
- 반영 명령: `scripts/clean_raw.py` → `scripts/build_db.py` → `scripts/verify_db.py` → `scripts/build_logistics.py` → `scripts/build_od.py` → `scripts/build_flow.py`

### 유통시설·생산단지·수출단지 (자세히 보기의 시설 점) (수동 파일)
- 확인 주기: 3개월 — 분기마다 공공데이터포털에 새 파일이 있는지 확인
- 공공데이터포털(data.go.kr)에서 받아 at_data/에 원래 파일 이름 그대로 넣는다 (같은 자료의 예전 파일은 지운다):
- · 전국미곡처리장표준데이터, 전국농산물산지유통센터(APC) 표준데이터 — 표준데이터, 자료를 낸 지자체만 들어 있다
- · 농림축산식품부_6차산업 인증 사업자 현황 (CSV) — 지금 파일은 2020년
- · 한국농수산식품유통공사_수출전문농가단지 정보 (CSV)
- · 농림축산검역본부 신선 농산물 수출검역단지 현황 — https://www.data.go.kr/data/15118469/fileData.do (해마다 7월 무렵)
- · 국비지원 로컬푸드 직매장 운영현황 — 2021년 자료뿐, 새 자료가 나오면 바꾼다
- 과수 생산단지(농사로)는 명령이 직접 받는다. 좌표는 VWorld로 찾고 결과는 at_data/cache에 남는다.
- 넣을 자리: `at_data/전국미곡처리장표준데이터-*.xls`, `at_data/전국농산물산지유통센터_APC_표준데이터-*.xls`, `at_data/농림축산식품부_6차산업 인증 사업자 현황_*.csv`, `at_data/한국농수산식품유통공사_수출전문농가단지 정보_*.csv`, `at_data/*수출검역단지*.xlsx`, `at_data/국비지원+로컬푸드+직매장*.xlsx`
- 반영 명령: `scripts/fetch_fruit_area.py` → `scripts/build_facilities.py`
