# 소개 영상 기획 (intro.html)

탭 줄 맨 앞(주요통계 앞) '소개' 버튼 → intro.html. 약 1분 46초.
영상 파일이 아니라 코드로 그린다. 지도·숫자는 사이트 자료(data/*.js)에서 뽑고, 실제 화면은 배포 사이트를 캡처해 넣는다.

## 1. 원칙

- **11개 화면을 전부** 보여 준다. 화면마다 "무엇이다"가 아니라 **그 화면만의 특장점을 숫자로** 보여 준다.
- **실체를 보여 준다**: 실제 현황판 화면을 브라우저 창에 넣고, 커서가 시도·시군을 고르고 위성지도를 여는 모습까지 보여 준다.
- 마지막에 **만든 이**와 그 생각을 보여 준다.

## 2. 장면 (초)

| 5–12 | 01 주요통계 | 3D 지도, 경지면적만큼 솟는 168개 시군 | 31개 지표 · 팜맵 1,118만 필지 직접 분석 · 농경지 중앙값 807㎡ · 논 경지정리율 |
| 12–21 | 02 실제 화면 | 브라우저 창, 커서가 전라남도 → 해남군 선택, 칸 표시 | 고르면 모든 칸이 그 시군 숫자로 · 전년 대비 띠 · 시도 안 순위 · 주소 공유 |

08~13은 화면 캡처를 쓰지 않는다(화면은 02·03과 14의 벽에서 보인다). 장면마다 그림 종류와 배치를 다르게 한다.

숫자는 모두 `scripts/build_intro.mjs`가 자료에서 계산한다(손으로 적지 않는다).

## 3. 색

사이트 색(먹색 바탕, 호박 #f5a524, 들판 초록 #5fb37c)을 잇는다. 장면마다 배경 빛 두 색이 바뀐다(palette.js SCENE_GLOW).
벼 예측(파랑↔호박), 물류(보낸 곳 #ffd28a → 받은 곳 #9fd1ff), 국가데이터처 #5fb3ff·KREI #5fb37c는 각 탭과 같은 색.

## 4. 배경음악

`src/intro/audio.js`가 Web Audio API로 합성한다(음원 파일 없음, 112 BPM, A단조). 장면마다 곡조가 바뀐다 — 장면 시작이 늘 마디 첫 박:

| 장면 | 곡조 |
|---|---|
| 열기 | 북 없이 패드와 종소리, 상승음 → 쿵 |
| 주요통계 | 영웅적: 4박 킥·베이스·금관풍 화음 찌르기 (Am–F–C–G) |
| 실제 화면 | 가볍고 기술적: 16분 플럭·하이햇, 커서 클릭에 클릭음 |
| 위성지도 | 우주적: 반박자 북, 필터가 열리는 패드, 확대마다 휘익 |
| 벼 작황 | 따뜻하게: 피아노 분산화음(C–G–Am–F), 정확도 공개에 딩, 선율 A |
| 직불금 | 행진: 스네어 꾸밈음, 베이스 맥박 (F–G–Em–Am) |
| 물류동향 | 질주: 16분 하이햇, 옥타브 베이스, 선율 B |
| 농사용 전기 | 전기적: 펌핑 패드, 필터가 쓸리는 톱니 아르페지오, 긴장 화음(…–E) |
| 08~13 | 장면마다 다른 아르페지오와 짧은 동기, 11번부터 한 음 올려 고조 |
| 자료 수집 현황 | 빌드업: 킥·스네어 롤이 촘촘해짐 |
| 만든 이 | 북 없이 피아노와 선율, 잔향 |
| 닫기 | 큰 화음과 종소리로 마무리 |

처음엔 꺼져 있고(브라우저 자동 재생 정책) 영상 오른쪽 위 '소리 켜기' 또는 조작 줄 스피커로 켠다. 음량 막대, M 키.

## 5. 조작

언제나 처음부터 자동 재생(움직임 줄이기 설정과 상관없이), 진행 막대(끌어 감기, 장면 눈금), 스페이스 재생/멈춤, ←/→ 앞뒤 장면, 장면마다 "○○ 화면 열기 →".

## 6. 파일과 갱신

- `intro.html`, `assets/intro/intro.css`, `src/intro/*.js` → `assets/intro/intro.js` (esbuild)
- 자료: `node scripts/build_intro.mjs` → `assets/intro/intro_data.js` (자료 갱신 뒤 다시 돌린다)
- 캡처: `node scripts/intro_shots.mjs` (논 NDVI는 `ONLY=ndvi NDVI_Z=1 NDVI_FX=0.3 NDVI_FY=0.42`, 한여름 맑은 날 자동 선택) → `assets/intro/shots/*.webp`, `shots.json` (배포 사이트를 찍는다. 화면이 바뀌면 다시 돌린 뒤 build_intro)
