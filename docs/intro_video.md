# 소개 영상 기획 (intro.html)

탭 줄 맨 앞(주요통계 앞) '소개' 버튼 → intro.html. 약 1분 42초.
영상 파일이 아니라 코드로 그린다. 지도·숫자는 사이트 자료(data/*.js)에서 뽑고, 실제 화면은 배포 사이트를 캡처해 넣는다.

## 1. 원칙

- **11개 화면을 전부** 보여 준다. 화면마다 "무엇이다"가 아니라 **그 화면만의 특장점을 숫자로** 보여 준다.
- **실체를 보여 준다**: 실제 현황판 화면을 브라우저 창에 넣고, 커서가 시도·시군을 고르고 위성지도를 여는 모습까지 보여 준다.
- 마지막에 **만든 이**와 그 생각을 보여 준다.

## 2. 장면 (초)

| 5–12 | 01 주요통계 | 3D 지도, 경지면적만큼 솟는 168개 시군 | 31개 지표 · 팜맵 1,118만 필지 직접 분석 · 농경지 중앙값 807㎡ · 논 경지정리율 |

| 21–29 | 03 위성지도 | '위성지도 보기' 클릭 → 항공영상·필지·유통시설 → Sentinel-2 NDVI | 유통시설 3,834곳 · Sentinel-2 10m 5일 · 레이더 |

숫자는 모두 `scripts/build_intro.mjs`가 자료에서 계산한다(손으로 적지 않는다).

## 3. 색

사이트 색(먹색 바탕, 호박 #f5a524, 들판 초록 #5fb37c)을 잇는다. 장면마다 배경 빛 두 색이 바뀐다(palette.js SCENE_GLOW).
벼 예측(파랑↔호박), 물류(보낸 곳 #ffd28a → 받은 곳 #9fd1ff), 국가데이터처 #5fb3ff·KREI #5fb37c는 각 탭과 같은 색.

## 4. 조작

자동 재생, 진행 막대(끌어 감기, 장면 눈금), 스페이스 재생/멈춤, ←/→ 앞뒤 장면, 장면마다 "○○ 화면 열기 →".

## 5. 파일과 갱신

- `intro.html`, `assets/intro/intro.css`, `src/intro/*.js` → `assets/intro/intro.js` (esbuild)
- 자료: `node scripts/build_intro.mjs` → `assets/intro/intro_data.js` (자료 갱신 뒤 다시 돌린다)
- 캡처: `node scripts/intro_shots.mjs` → `assets/intro/shots/*.webp`, `shots.json` (배포 사이트를 찍는다. 화면이 바뀌면 다시 돌린 뒤 build_intro)
