# 소개 영상 기획 (intro.html)

탭 줄 오른쪽 '만든이' 앞에 '소개' 버튼을 두고, 누르면 30초 소개 웹영상(intro.html)을 연다.
영상 파일이 아니라 코드로 그린다. 그래서 숫자·지도는 사이트와 같은 실제 자료다.

## 1. 누구에게, 무엇을

- 처음 온 사람: "여기서 무엇을 볼 수 있나"를 30초 안에 알게 한다.
- 메시지 하나: **공개 통계로 우리 지역 농업을 한 화면에.**
- 기능 11개를 다 똑같이 보여 주지 않는다. 그림이 강한 4개(주요통계 지도, 벼 작황 예측, 물류 흐름, 농사용 전기)를 장면으로 만들고 나머지 7개는 한 장면에 모은다.

## 2. 장면 구성 (30초)

| 시간 | 장면 | 화면 | 기술 | 자료 |
|---|---|---|---|---|
| 0–4초 | 열기 | 흩어진 빛 입자 9천 개가 모여 한반도 남쪽 시군 지도가 된다. 제목이 글자 단위로 떠오른다 | Three.js 입자(셰이더), GSAP | geo.js 시군 경계 |
| 4–10초 | 주요통계 | 지도가 기울며 시군 168곳이 경지면적만큼 솟는다. 큰 3곳 이름표 | Three.js 돌출 지도·조명 | data.js 경지면적 |
| 10–16초 | 벼 작황 | 기둥이 내려앉고 시군 색이 2026 예측 단수(평년 대비)로 바뀐다. 오른쪽에 전국 단수 선과 7월~11월 예측 7번이 모여드는 그림 | Three.js 색 전환, SVG 선 그리기 | rice.js 예측·평년·국가데이터처·KREI |
| 16–21초 | 물류동향 | 어두운 지도 위로 시군 간 물류 흐름 60개가 빛의 호로 흐른다(보낸 곳 주황 → 받은 곳 하늘색, 사이트 물류 화면과 같은 색) | Canvas 2D 가산 합성 | od.js 2025 컨테이너 |
| 21–25초 | 농사용 전기 | 2010~2026 월별 사용량 200개월이 나선으로 감기며 계절 리듬이 드러난다 | Canvas 2D | power.js 전국 사용량 |
| 25–28초 | 그리고 더 | 나머지 7개 화면 카드가 차례로 뒤집혀 나타난다 | SVG 아이콘, GSAP | — |
| 28–30초 | 닫기 | 로고·주소·바로가기 | GSAP | — |

배경 전체에는 WebGPU(안 되면 WebGL2) 셰이더로 그린 어두운 오로라 빛이 흐르고, 장면마다 색이 바뀐다.

## 4. 조작

- 자동 재생, 끝나면 마지막 장면에 머문다.
- 아래 진행 막대: 장면 이름을 누르면 그 장면으로 간다. 막대를 끌어 감기.
- 재생/멈춤(스페이스), 다시 보기, 장면마다 "이 화면 열기" 바로가기.
- 움직임 줄이기 설정을 켠 사람에게는 멈춘 채로 열고 재생 버튼을 보인다.

## 5. 파일

- `intro.html`, `assets/intro/intro.css`
- `src/intro/*.js` → `scripts/build_intro.mjs`가 esbuild로 묶어 `assets/intro/intro.js` (Three.js·GSAP는 npm으로 설치, 쓰는 부분만 묶음)
- `scripts/build_intro.mjs`가 사이트 자료에서 영상용 자료만 뽑아 `assets/intro/intro_data.js`로 쓴다. 자료가 갱신되면 다시 돌린다: `node scripts/build_intro.mjs`
- `assets/about.js`: '소개' 버튼 추가
